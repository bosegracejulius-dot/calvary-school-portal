# Calvary School Portal

BUILD A COMPLETE, MODERN SCHOOL WEBSITE FOR CALVARY GROUP OF SCHOOLS



Build a professional, beautiful, responsive, fully functional website for Calvary Group of Schools, Arepo, Ogun State, Nigeria.



This is a complete school website project, not just a landing page. It should look like a premium, professionally developed school website that parents, students, teachers and visitors can use on phones, tablets and computers.



1. SCHOOL IDENTITY



School name: Calvary Group of Schools

Main campus: 1–5 Calvary Avenue, Pipeline, Arepo, Obafemi Owode LGA, Ogun State, Nigeria.

Website: https://www.calvarygroupofschools.com/



The school has:



- Pre-school

- Primary School

- Junior Secondary School

- Senior Secondary School



Use the existing official school website as a reference for verified information, including the school's history, founder, mission, vision, pledge, facilities and contact details.



Do not invent school history, staff names, fees, rules, examination results, policies or achievements. If information is missing, use clearly labelled placeholders until it can be confirmed.



2. DESIGN AND VISUAL STYLE



Create a premium, modern, welcoming and educational design.



The website should have:



- A professional school identity and consistent branding.

- An attractive homepage with a strong hero section.

- Beautiful school-related photography, using approved images or suitable placeholders.

- Smooth animations and transitions.

- Modern cards, rounded corners and clean layouts.

- Professional typography.

- Attractive buttons and navigation.

- A consistent colour scheme based on the school's existing branding. Check the official website for its colours rather than inventing a new identity.

- A mobile-first responsive layout.



The website must feel like a real, established educational institution's website, not a basic school assignment template.



3. WEBSITE PAGES



Create the following pages and connect them through a working navigation menu.



HOME



Include:



- A welcoming hero section.

- A short introduction to Calvary Group of Schools.

- A prominent admissions/enquiry button.

- A brief overview of the school's educational levels.

- Highlights of the school's facilities.

- Mission, vision and values.

- News and announcements.

- Upcoming events.

- Testimonials only if genuine approved testimonials are provided.

- A strong footer with contact information and useful links.



ABOUT US



Include:



- School history.

- Founder information.

- Mission and vision.

- School philosophy.

- Core values.

- School pledge.

- Educational approach.



Use verified information from the official website. Leave unverified details clearly marked for confirmation.



ACADEMICS



Create separate sections for:



- Pre-school.

- Primary School.

- Junior Secondary School.

- Senior Secondary School.



Include academic information, learning approach, subjects and examination information only where verified.



ADMISSIONS



Create an attractive admissions page with:



- Admissions introduction.

- Admission steps.

- Requirements.

- Enquiry form.

- Contact information.

- Frequently asked admissions questions.



Do not invent admission fees, deadlines or requirements. Use placeholders for information that needs confirmation.



FACILITIES



Create an attractive facilities page featuring available facilities such as:



- Science laboratories.

- Sports facilities.

- School hall.

- School buses.

- Other verified learning and recreational facilities.



Use approved school photographs where available. Do not present unverified facilities as confirmed facts.



NEWS AND EVENTS



Create a news and events section where visitors can see:



- School announcements.

- Academic events.

- Sporting activities.

- Celebrations.

- Important dates.

- School activities.



Include a structure that allows an authorised administrator to add, edit and remove announcements and events.



Do not treat old events or calendar information from the existing website as upcoming events. Dates must be verified before publication.



STUDENT LIFE



Include sections for:



- Extracurricular activities.

- Sports.

- Student development.

- Student achievements, when verified.



CONTACT US



Include:

- Map/location section.

- Social media links only where official accounts are confirmed.



4. CALVARY AI — THE SCHOOL'S INTELLIGENT AI ASSISTANT



This is one of the most important features of the website.



Build a powerful AI assistant called CALVARY AI.



Calvary AI should function as an intelligent digital school assistant that can answer questions about Calvary Group of Schools using verified school information.



It should be able to answer questions about:



- The school's history.

- The founder and background of the school.

- School rules and regulations.

- Student discipline and conduct.

- School values and pledge.

- Mission and vision.

- Academic programmes.

- Subjects and educational levels.

- Admissions and admission requirements.

- School facilities.

- Extracurricular activities.

- School calendar and events.

- School policies.

- Frequently asked questions.

- Contact information.

- Other information contained in the school's approved knowledge base.



AI KNOWLEDGE SYSTEM



Do not create a chatbot that simply gives random answers.



Build a proper school knowledge system.



The assistant should use verified school information from:



- The official school website.

- School handbooks.

- School rules and regulations.

- Official brochures.

- Approved school policies.

- Academic documents.

- Official announcements.

- School calendars.

- Other documents uploaded by authorised administrators.



Use a retrieval-based knowledge system (RAG) so that Calvary AI searches the school's information before generating answers.



Allow authorised administrators to upload and update school documents so that the AI's knowledge can grow over time.



AI ANSWERING RULES



Calvary AI must:



- Give clear, intelligent and friendly answers.

- Understand normal questions written in everyday language.

- Answer based on verified school information.

- Never invent school rules, fees, dates, policies or historical facts.

- Say when it does not have enough information.

- Direct users to school management when a question requires an official decision.

- Identify the source of important answers when possible.

- Never reveal private student or staff information.

- Never pretend to be a human teacher or school administrator.



AI CHAT INTERFACE



Create a beautiful chat interface with:



- A floating Calvary AI button visible throughout the website.

- A professional chat window.

- A welcome message.

- Suggested questions.

- A typing indicator.

- Clear conversation messages.

- A new-chat option.

- Mobile-friendly layout.



Suggested questions:



- What is the history of Calvary Group of Schools?

- What are the school's rules?

- What educational levels does the school offer?

- How do I apply for admission?

- What facilities does the school have?

- What is the school's pledge?

- How can I contact the school?



The assistant must be connected to a real AI backend when configured. Do not present a non-functional demo as a working AI.



AI SECURITY



- Keep AI API keys and secrets on the backend.

- Never expose private keys in frontend code.

- Use secure backend functions for AI requests.

- Restrict document management to authorised administrators.

- Do not put private school documents, student records or API keys in the public GitHub repository.

- Make it possible to update the AI knowledge base without rebuilding the entire website.



If a paid AI provider or API key is required, build the integration structure securely and explain what needs to be configured. Do not pretend the AI is fully operational until it has been connected and tested.



5. ADMIN DASHBOARD



Build a secure administrator dashboard.



Authorised administrators should be able to:



- Add, edit and delete news.

- Publish announcements.

- Add and update school events.

- Manage website content.

- Upload approved school documents.

- Update Calvary AI's knowledge base.

- Manage admissions enquiries.

- Update contact information.



Use proper authentication and access controls. Normal visitors must not be able to access administrative functions.



6. FUNCTIONALITY



Make the website genuinely functional.



Implement:



- Working navigation.

- Working contact forms.

- Working admissions enquiry forms.

- Responsive menus.

- Search functionality for website content.

- News and event management.

- Secure administrator authentication.

- Document upload and management.

- Calvary AI integration structure.

- Proper loading, success and error states.



Do not create buttons that look functional but do nothing.



Use a suitable database and backend. Lovable Cloud can be used for authentication, database, file storage and backend functions if available. Keep the architecture simple and affordable.



7. SEO AND PERFORMANCE



Optimise the website for:



- Google search.

- Mobile devices.

- Fast loading.

- Accessibility.

- Search engine metadata.

- Clear page titles and descriptions.

- Social sharing previews.



Use clean, maintainable code and a sensible project structure.



8. PRIVACY AND SAFETY



- Do not expose API keys.

- Do not publish private school records.

- Do not upload identifiable student photographs without permission.

- Protect contact and admissions information.

- Use secure authentication for administrators.

- Only publish school policies and documents that are approved for public use.



9. PROJECT DEVELOPMENT APPROACH



Build the project in a way that can be continued by another student developer using the public GitHub repository.



Requirements:



- Keep the code organised and understandable.

- Use reusable components.

- Include a README explaining how to run and continue the project.

- Include setup instructions.

- Include a list of environment variables required, but never include actual secret values.

- Make the project easy to download and continue on another computer.



Prioritise free or low-cost services wherever possible. Do not add paid subscriptions, billing systems or unnecessary paid integrations.



10. FINAL EXPECTATION



The final result should be a complete, impressive, professional school website for Calvary Group of Schools, with Calvary AI as its standout feature.



It should combine:



- A premium school website.

- A complete information platform.

- A news and events system.

- An admissions enquiry system.

- An administrator dashboard.

- An intelligent AI school assistant.



Build the actual working website, not just a design mockup.



Start by creating the full website structure and visual design, then implement the functional features. Make sure every section works on mobile and desktop.



Where information is unavailable, use clearly labelled placeholders rather than making things up.



The goal is to create a website that can proudly represent Calvary Group of Schools and can be expanded in the future.
